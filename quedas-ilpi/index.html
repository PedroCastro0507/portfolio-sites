      Ajustar conteúdo do formulário para a professora · sem programar

      Tudo o que aparece na tela (títulos, rótulos das etapas, perguntas, opções, mensagens e o exemplo fictício) está no texto abaixo. Altere só o que está entre aspas e clique em Aplicar neste navegador.

      1. Para trocar um texto, edite o valor entre aspas, por exemplo "rotulo": "Local do evento".
      2. Para incluir uma opção, acrescente um item na lista "opcoes", separado por vírgula.
      3. "obrigatorio": true exige a resposta antes de avançar; false torna opcional.
      4. "mostrarSe" faz uma pergunta aparecer só quando outra tiver a resposta indicada.
      5. As mudanças valem só neste navegador. Para valer para todos que abrirem o link, baixe a configuração e envie ao responsável pelo protótipo.
